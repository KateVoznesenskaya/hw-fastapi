Инструкция как запустить тесты:

Чтобы запустить код нужно в файле .env указать данные для доступа к базе данных.

Чтобы запустить функциональные и юнит тесты coverage run -m pytest. Посмотреть отчет о запуске тестов и тестовое покрытие coverage report.

Чтобы запустить нагрузочное тетирование нужно запустить приложение uvicorn main:app и потом запустить тестирование locust -f tests/test-load.py.
